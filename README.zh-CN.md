# VisiDot

*[English →](README.md)*

一个离线、纯静态的网页应用，用于**色觉自测**与**色卡复核**，围绕石原式（伪同色）色盲检查图构建。纯 HTML/CSS/JS —— 无需构建、无框架、无后端。

VisiDot 包含两个页面：

| 页面 | 文件 | 用途 |
|------|------|------|
| **复核台** | `index.html` | 以画廊方式浏览色卡、全屏查看单张、施加红/绿滤色遮罩、编辑记录的关键图形、标记已复核，并将答案表导出为 JSON。 |
| **色觉测验** | `quiz.html` | **练习模式**（不限时、即时反馈、滤色遮罩辅助）或**考试模式**（随机抽题、每题限时、计分报告 + 逐题回顾）。 |

两个页面共用同一套平静的「养生浅色」设计系统（青 + 健康绿配色、Raleway/Lora 字体），并在桌面与移动端自适应布局。

## 功能特性

- **滤色遮罩** —— 红/绿 multiply 叠加层，配色温 / 色调 / 强度滑轨，辅助辨认色卡。
- **平台自适应界面** —— 复核台会检测运行平台，在网页双栏控制台与原生风格的 iOS / Android 外壳之间切换。桌面可用 `?platform=ios|android|web` 预览任意外壳。
- **色盲友好界面** —— 分类用「图标 + 文字」表达，绝不单靠颜色传达信息。
- **无障碍** —— 键盘快捷键、焦点态、`prefers-reduced-motion` 支持、AA 级正文对比度。
- **离线优先** —— 全部由静态文件运行；无网络请求、无追踪。

## 快速开始

需要 **Python 3**（仅用标准库）。

```bash
python serve.py
```

它会在 `http://127.0.0.1:8770/` 启动本地静态服务器，并在浏览器打开测验页。

平台启动器：

- **Windows** —— 双击 `启动.bat`
- **Ubuntu / Linux** —— 运行 `./start.sh`（首次先 `chmod +x start.sh` 赋予可执行权限）

任何静态文件服务器也可以，例如 `python -m http.server`。

## 色卡图片（不含在内）

色卡扫描图**未随本仓库分发** —— 它们是受版权保护的医学检测材料。应用会从以下路径读取：

```
v5/v5-<页码>-areal.webp
v6/v6-<页码>-areal.webp
```

请自备色卡图片放到上述路径。应用读取的「页码→答案」映射位于：

- `data.js` —— 复核台色卡列表（`window.PLATE_DATA`）
- `quiz-data.js` —— 测验答案表（`window.QUIZ_KEY`），据此构建题库

`reference/` 目录存放用于生成这些数据文件的答案表 JSON 与页码映射。

## 项目结构

```
index.html        复核台（单页应用）
quiz.html         色觉测验（单页应用）
data.js           复核台色卡数据
quiz-data.js      测验答案表 + 题库构建
app-icon.png      应用图标 / favicon
serve.py          本地静态服务器（自动开浏览器、优雅关闭）
启动.bat          Windows 一键启动
start.sh          Ubuntu / Linux 启动脚本
reference/        答案表 JSON 与页码映射说明（非运行时依赖）
v5/ v6/           色卡图片 —— 请自备（已被 git 忽略）
```

## 键盘快捷键

**复核台：** `←`/`→` 上一张/下一张 · `G`/`R` 切换绿/红遮罩 · `F` 跳到下一张待复核。
**测验：** `1`–`4` 选择选项 · `Enter` 下一题。
